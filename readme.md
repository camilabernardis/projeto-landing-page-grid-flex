## 📖 Sobre o projeto

Este projeto foi proposto pelo curso de extensão do **[Dev em Dobro](https://www.devemdobro.com/)** para construir uma **landing page simples**, passo a passo, junto com o professor.

A página é de uma agência fictícia, a **Agência XYZ**, e foi pensada para praticar a combinação de dois recursos fundamentais do CSS moderno: **Grid** e **Flexbox**, tanto no desktop quanto no mobile.

## ✨ O que tem na página

- **Menu de navegação** com as seções About, Services, Projects e Contact
- **Seção principal (hero)** com chamada e textos em destaque, com botões "Saiba mais"
- **Serviços** apresentados em blocos com ícones
- **Galeria de imagens** organizada em grid
- **Rodapé** com menu e ícones de redes sociais
- **Layout responsivo**, que se adapta a telas grandes e pequenas

## 🛠️ Tecnologias

- **HTML5**: estrutura da página
- **CSS3**: estilização, variáveis CSS e organização do código em vários arquivos
- **CSS Grid**: layout geral e galeria de imagens
- **Flexbox**: alinhamento de menu, textos e elementos
- **Font Awesome**: ícones de redes sociais e da interface

## 📂 Estrutura do projeto

```
projeto-landing-page-grid-flex/
├── index.html                # Página principal
├── README.md
└── src/
    ├── css/
    │   ├── reset.css         # Zera os estilos padrão do navegador
    │   ├── variables.css     # Variável CSS com a largura máxima da página (1920px)
    │   ├── style.css         # Estilos principais
    │   ├── menu.css          # Estilos do menu
    │   └── font-awesome.css  # Biblioteca de ícones
    ├── images/               # Fotos, ícones e prints do projeto
    └── webfonts/             # Fontes dos ícones do Font Awesome
```

## 🚀 Como rodar localmente

```bash
# 1. Clone o repositório
git clone https://github.com/camilabernardis/projeto-landing-page-grid-flex.git

# 2. Entre na pasta
cd projeto-landing-page-grid-flex

# 3. Abra o index.html no navegador
```

Não precisa instalar nada, é só abrir o `index.html`. 😉

## 💪 Facilidades e desafios

**O que foi tranquilo:** o **Grid** como base de layout facilitou muito o meu entendimento da estilização. Usá-lo junto com o **Flexbox** foi um experimento bem interessante, e essa combinação ajudou bastante também na hora de fazer o **responsivo**.

**Desafios:** acompanhando o professor, não tive grandes dificuldades para realizar o projeto.

## 💡 Aprendizados

- Montar um layout completo com **CSS Grid**
- Combinar **Grid e Flexbox** no mesmo projeto, cada um onde faz mais sentido
- Facilitar o **responsivo** com Grid e Flex
- Criar uma **variável CSS** (`:root`) para guardar a largura máxima da página
- Organizar o CSS em **vários arquivos** (reset, variáveis, menu e estilos)
- Usar **Font Awesome** para ícones
- Estruturar uma **landing page** do zero
